### 一、模型代码概览

在 `tickets/models.py` 中创建了 **6 个数据模型**：

#### 1. TicketType (工单类型)
- 字段：`name`, `code`, `description`, `is_active`, `created_at`, `updated_at`
- 约束：`name` 和 `code` 唯一

#### 2. CustomField (自定义字段配置)
- 字段：`ticket_type` (外键), `field_name`, `field_code`, `field_type`, `is_required`, `options`, `placeholder`, `sort_order`, `is_active`
- 约束：`(ticket_type, field_code)` 联合唯一
- 选项：`input`/`select`/`textarea`

#### 3. Ticket (工单主表)
- 公共字段：`ticket_no`, `ticket_type` (外键), `source`, `status`, `priority`, `user_name`, `user_phone`, `user_email`, `receiver`, `handler`, `handle_department`
- 自动生成工单编号：格式 `OPPO-YYYYMMDD-XXXX`（如 `OPPO-20260427-0001`）
- 来源选项：`phone`/`website`/`app`/`wechat`/`offline`
- 状态选项：`pending`/`processing`/`resolved`/`closed`
- 优先级选项：`low`/`medium`/`high`/`urgent`

#### 4. TicketFieldValue (工单自定义字段值)
- 字段：`ticket` (外键), `custom_field` (外键), `value`
- 约束：`(ticket, custom_field)` 联合唯一

#### 5. TransferRecord (转派记录)
- 字段：`ticket` (外键), `from_handler`, `from_department`, `to_handler`, `to_department`, `transfer_reason`, `operator`

#### 6. EditHistory (编辑历史记录)
- 字段：`ticket` (外键), `field_name`, `old_value`, `new_value`, `operator`

### 二、关键代码片段说明

#### 1. `login_required` 装饰器 (`tickets/views.py:6-16`)

```python
def login_required(view_func):
    @wraps(view_func)
    def wrapper(request, *args, **kwargs):
        if not request.session.get('is_logged_in'):
            login_url = reverse('login')
            next_url = request.get_full_path()
            if next_url:
                return redirect(f'{login_url}?next={next_url}')
            return redirect(login_url)
        return view_func(request, *args, **kwargs)
    return wrapper
```

- 使用 `@wraps` 保持原函数元数据
- 检查 `session` 中的 `is_logged_in` 标记
- 未登录时重定向到登录页，并携带 `next` 参数（登录后跳转回原页面）

#### 2. `login_view` 登录视图 (`tickets/views.py:19-38`)

```python
def login_view(request):
    if request.method == 'POST':
        role = request.POST.get('role')
        
        if role == 'super_admin':
            request.session['is_logged_in'] = True
            request.session['role'] = 'super_admin'
            request.session['username'] = '超级管理员'
            
            next_url = request.GET.get('next')
            if next_url:
                return redirect(next_url)
            return redirect('ticket_list')
        
        return render(request, 'login.html', {'error_message': '请选择有效的角色'})
    
    if request.session.get('is_logged_in'):
        return redirect('ticket_list')
    
    return render(request, 'login.html')
```

- **POST 请求**：处理登录，在 `session` 中存储用户信息
- **GET 请求**：已登录则重定向到工单列表，否则显示登录页面
- 支持 `next` 参数，登录成功后跳转到原请求页面

#### 3. `logout_view` 退出视图 (`tickets/views.py:41-43`)

```python
def logout_view(request):
    request.session.flush()
```
