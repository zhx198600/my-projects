# 创意剧本生成器 - Product Requirement Document

## Overview
- **Summary**: 一个Web前端应用，允许用户输入创意文字或想法，系统将其扩展为3-5集的小剧本，每集包含场景描述、角色对话和剧情发展，最终结局出人意料。
- **Purpose**: 帮助用户将简单的创意想法快速转化为有结构、有创意、有反转结局的多集剧本内容。
- **Target Users**: 创意写作者、剧本爱好者、内容创作者、广告文案人员

## Goals
- 提供简单直观的用户输入界面
- 生成3-5集结构完整的剧本文字
- 剧本内容具有创意性和想象力
- 结局设计出乎用户意料但合乎逻辑
- 支持查看、编辑和导出生成的剧本

## Non-Goals (Out of Scope)
- 不实现真实的AI模型（使用Mock数据模拟生成过程）
- 不支持多用户协作编辑
- 不实现剧本视频化或音频化
- 不提供历史记录云端存储（仅本地存储）
- 不支持社交分享功能

## Background & Context
- 这是一个全新的前端项目，从零开始构建
- 使用 React + TypeScript 技术栈
- 样式采用 Tailwind CSS
- 所有数据使用纯前端 Mock，模拟生成延迟和效果

## Functional Requirements

### FR-1: 创意输入功能
- 用户可以通过文本框输入创意文字或想法
- 支持输入最少10字，最多500字的内容
- 提供输入字数统计和提示

### FR-2: 剧本生成功能
- 系统基于用户输入生成3-5集的剧本
- 每集包含：集数标题、场景描述、角色列表、对话内容、场景转换提示
- 生成过程显示加载动画和进度提示
- 生成完成后展示完整剧本内容

### FR-3: 剧本展示与导航
- 支持按集数切换查看剧本内容
- 提供剧本大纲概览（所有剧集标题列表）
- 支持滚动阅读长内容
- 高亮显示当前阅读的集数

### FR-4: 结局反转设计
- 每生成的剧本必须包含出人意料的结局
- 结局需与前文伏笔呼应，合乎逻辑但超出预期
- Mock数据中包含多种类型的反转结局模板

### FR-5: 本地保存与导出
- 支持将生成的剧本保存到浏览器本地存储
- 支持导出为纯文本文件
- 支持复制剧本内容到剪贴板

## Non-Functional Requirements

### NFR-1: 性能表现
- 页面首次加载时间 < 2秒
- 生成过程模拟延迟 2-5秒（营造真实AI生成感）
- 交互响应时间 < 100ms

### NFR-2: 可用性
- 界面简洁直观，无需引导即可使用
- 支持响应式设计，适配桌面和移动设备
- 错误提示友好，帮助用户理解问题

### NFR-3: 可维护性
- 代码结构清晰，组件分层合理
- 使用TypeScript确保类型安全
- Mock数据与业务逻辑分离

## Constraints

### 技术约束
- **前端框架**: React 18 + TypeScript
- **样式方案**: Tailwind CSS
- **构建工具**: Vite（推荐）或 Create React App
- **数据存储**: 浏览器 localStorage
- **数据来源**: 纯前端 Mock 数据

### 业务约束
- 剧本集数固定为3-5集，不可配置
- Mock数据需预设多种不同风格的剧本模板
- 生成过程是"模拟"的，不依赖真实AI服务

## Assumptions

- 用户具备基本的Web浏览器使用能力
- 用户输入的创意文字具有一定的可扩展性（非完全无意义内容）
- Mock数据可以覆盖大多数常见的创意方向
- 用户主要在桌面设备上使用，但移动端也需要支持

## Acceptance Criteria

### AC-1: 输入页面正常工作
- **Given**: 用户打开应用首页
- **When**: 用户在输入框中输入创意文字
- **Then**: 
  - 显示当前输入字数统计
  - 字数少于10字时"生成"按钮禁用并提示
  - 字数超过500字时阻止继续输入并警告
- **Verification**: `programmatic`

### AC-2: 生成过程模拟正常
- **Given**: 用户已输入有效创意文字
- **When**: 用户点击"生成剧本"按钮
- **Then**:
  - 显示加载动画和生成进度提示
  - 模拟生成过程持续2-5秒
  - 期间禁用重复提交
- **Verification**: `programmatic`

### AC-3: 生成结果格式正确
- **Given**: 剧本已成功生成
- **When**: 查看生成的剧本内容
- **Then**:
  - 包含3-5集内容
  - 每集包含：标题、场景描述、角色、对话
  - 内容与用户输入的创意主题相关
- **Verification**: `programmatic`

### AC-4: 结局反转特性验证
- **Given**: 查看完整生成的剧本
- **When**: 阅读到最后一集结局
- **Then**:
  - 结局内容与用户常规预期不同
  - 结局有伏笔支撑，逻辑自洽
  - 用户阅读后产生"意外"感
- **Verification**: `human-judgment`

### AC-5: 剧集导航功能正常
- **Given**: 剧本已生成
- **When**: 用户点击不同集数标签
- **Then**:
  - 正确切换显示对应集数内容
  - 当前选中的集数有视觉高亮
  - 滚动位置自动定位到内容顶部
- **Verification**: `programmatic`

### AC-6: 本地保存与导出功能
- **Given**: 剧本已生成
- **When**: 用户进行保存/导出/复制操作
- **Then**:
  - 保存：剧本内容写入localStorage，可刷新后恢复
  - 导出：生成可下载的.txt文件
  - 复制：内容成功复制到剪贴板
- **Verification**: `programmatic`

### AC-7: 响应式布局验证
- **Given**: 用户在不同屏幕尺寸设备上访问
- **When**: 切换桌面/平板/手机视口
- **Then**:
  - 布局自适应调整，无内容溢出
  - 按钮和输入控件可点击区域足够大
  - 文字可读性良好
- **Verification**: `human-judgment`
