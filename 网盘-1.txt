## 实现细节

### 后端预览接口 (`api/routes/files.ts:326`)
- 支持两种认证方式：`Authorization` header 或 `?token=` 查询参数（方便 `<img>`、`<iframe>`、`<video>`、`<audio>` 标签使用）
- 设置 `Content-Disposition: inline` 支持内联预览
- 通过 `fs.createReadStream` 流式传输文件内容

### 预览模态框 (`src/components/Preview/FilePreview.tsx`)
- **图片**: `<img>` 标签显示，最大程度适配
- **PDF**: `<iframe>` 内嵌显示
- **文本**: `fetch` 获取内容后用 `<pre>` 显示，支持加载中/错误状态
- **视频**: `<video controls autoplay>` 播放
- **音频**: `<audio controls autoplay>` 播放
- **不支持类型**: 显示提示和下载按钮
- 支持 ESC 键关闭、点击背景关闭、头部下载按钮

### 类型判断逻辑
- `image/*` → 图片预览
- `application/pdf` → PDF 预览
- `video/*` → 视频预览
- `audio/*` → 音频预览
- `text/*` → 文本预览
- 其他 → 不支持（显示下载按钮）

## 项目完成总结

### 已实现的功能

**后端 API（Express + TypeScript + SQLite）：**

| 模块 | 接口 | 说明 |
|------|------|------|
| 用户认证 | POST /api/auth/register | 用户注册 |
| | POST /api/auth/login | 用户登录 |
| | GET /api/auth/me | 获取当前用户 |
| | POST /api/auth/logout | 登出 |
| 文件管理 | POST /api/files/upload | 上传文件（支持多文件、拖拽） |
| | GET /api/files | 获取文件列表（支持排序筛选） |
| | PUT /api/files/:id/rename | 重命名文件 |
| | PUT /api/files/:id/move | 移动文件 |
| | DELETE /api/files/:id | 删除文件 |
| | GET /api/files/:id/preview | 文件预览 |
| | GET /api/files/:id/download | 文件下载 |
| 文件夹管理 | POST /api/folders | 创建文件夹 |
| | GET /api/folders | 获取文件夹列表 |
| | PUT /api/folders/:id | 重命名文件夹 |
| | DELETE /api/folders/:id | 删除文件夹（检查是否为空） |
| | GET /api/folders/:id/breadcrumb | 获取面包屑路径 |
| 分享链接 | POST /api/shares | 创建分享链接 |
| | GET /api/shares | 获取分享列表 |
| | DELETE /api/shares/:id | 删除分享 |
| | GET /api/s/:code | 公开访问分享 |
| 容量管理 | GET /api/user/storage | 获取存储信息 |
| | POST /api/user/storage/check | 检查容量 |

**前端界面（React + TypeScript + Tailwind CSS）：**

| 页面/组件 | 功能 |
|-----------|------|
| Login 页面 | 用户登录 |
| Register 页面 | 用户注册 |
| Dashboard 页面 | 网盘主界面 |
| SharePage 页面 | 公共分享页面 |
| Sidebar | 侧边栏（导航、存储进度） |
| Header | 顶部栏（搜索、上传、新建文件夹） |
| Breadcrumb | 面包屑导航 |
| FileList | 文件列表（列表/网格视图） |
| FilePreview | 文件预览（图片、PDF、文本、音视频） |
| DropZone | 拖拽上传 |
| NewFolderModal | 新建文件夹 |
| RenameModal | 重命名 |
| MoveModal | 移动文件 |
| ShareModal | 创建分享 |
| BatchToolbar | 批量操作工具栏 |

### 技术栈
- **前端**: React 18, TypeScript, Vite, Tailwind CSS, Zustand, Lucide React
- **后端**: Node.js, Express 4, TypeScript, better-sqlite3
- **认证**: JWT, bcryptjs
- **文件上传**: multer

### 访问地址
- 前端: http://localhost:5173/
- 后端 API: http://localhost:3001/

### 使用方式
1. 打开前端页面，注册新账号
2. 登录后进入网盘主界面
3. 上传文件、创建文件夹、预览文件、分享链接等
