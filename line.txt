### 2. 在组件中使用认证 (`useAuth`)

```tsx
'use client';

import { useAuth } from '@/contexts/AuthContext';

export default function LoginPage() {
  const { login, logout, user, isAuthenticated, isLoading } = useAuth();

  const handleLogin = async () => {
    const result = await login('admin', 'admin123');
    if (result.success) {
      // 登录成功，跳转到首页
    } else {
      console.error(result.error);
    }
  };

  if (isLoading) {
    return <div>加载中...</div>;
  }

  if (isAuthenticated) {
    return (
      <div>
        <p>欢迎, {user?.username}!</p>
        <button onClick={logout}>退出登录</button>
      </div>
    );
  }

  return <button onClick={handleLogin}>登录</button>;
}
```

### 3. 路由保护 (`useProtectedRoute`)

在需要登录才能访问的页面中使用：

```tsx
'use client';

import { useProtectedRoute } from '@/hooks/useProtectedRoute';

export default function DashboardPage() {
  const { isLoading } = useProtectedRoute();

  if (isLoading) {
    return <div>验证登录状态中...</div>;
  }

  return (
    <div>
      <h1>仪表盘</h1>
      <p>只有登录用户才能看到此页面</p>
    </div>
  );
}
```

#### 状态管理
- `users: User[]` - 用户列表数据
- `searchQuery: string` - 搜索关键词
- `isLoading: boolean` - 加载状态
- `showConfirm: boolean` - 确认对话框显示状态
- `targetUser: User | null` - 目标用户（用于确认操作）
- `targetAction: 'enable' | 'disable' | null` - 目标操作
- `isUpdating: boolean` - 更新中状态

#### 核心逻辑

1. **数据获取**: 
   - 页面加载时调用 `userApi.getUsers()`
   - 刷新按钮可手动重新获取

2. **搜索过滤**:
   - 使用 `useMemo` 优化过滤性能
   - 用户名包含关键词即匹配（大小写不敏感）

3. **启用/禁用用户流程**:
   ```
   点击按钮 → 设置 targetUser & targetAction → 显示 ConfirmDialog
                                                         ↓
   关闭 ← 失败显示错误 Toast ← 调用 userApi.updateUserStatus() ← 用户确认
                          ↓
                    成功: 显示成功 Toast + 更新本地列表
   ```

4. **确认对话框消息**:
   - **禁用**: `"确定要禁用该用户吗？禁用后该用户将无法登录。"`
   - **启用**: `"确定要启用该用户吗？"`
   - **按钮样式**: 禁用用 `danger`（红色），启用用 `primary`（蓝色）

5. **Toast 反馈**:
   - 使用 `useToast()` Hook
   - 成功时显示 `common.success`
   - 失败时显示 `common.error`
