# 联华保险客户档案全栈Web后台管理系统 - 产品需求文档

## Overview
- **Summary**: 构建一个完整的联华保险客户档案全栈Web后台管理系统，包含客户信息管理、销售管理、档案生命周期管理、服务管理、数据分析与报表五大核心模块。系统支持全量数据的关键字查询和Excel/PDF格式导出功能，为保险业务提供一站式数字化管理解决方案。
- **Purpose**: 解决保险行业客户档案分散、数据查询效率低、销售流程不规范、服务跟踪困难、数据分析能力薄弱等问题，实现客户全生命周期数字化管理。
- **Target Users**: 保险公司内勤管理人员、销售业务员、客服人员、数据分析人员、部门主管

## Goals
- 实现客户基本信息、投保信息、健康档案的集中化管理
- 建立完整的销售流程管理体系，包括线索、商机、合同、佣金管理
- 实现客户档案从创建、归档、借阅到销毁的全生命周期管理
- 建立服务工单系统，跟踪客户投诉、咨询、理赔等服务过程
- 提供多维度数据分析与报表功能，支持业务决策
- 所有业务数据支持关键字模糊查询和数据导出

## Non-Goals (Out of Scope)
- 不包含面向C端客户的移动端APP或小程序
- 不包含第三方支付系统集成
- 不包含AI智能客服功能
- 不包含复杂的工作流引擎
- 不支持多租户部署架构

## Background & Context
- 保险行业客户数据量大，档案管理一直是业务痛点
- 传统档案管理方式查询困难，容易丢失，无法追踪
- 销售过程缺乏系统化管理，转化率难以提升
- 客户服务质量无法有效监控和评估
- 业务决策缺乏数据支撑

## Functional Requirements
- **FR-1**: 客户信息管理 - 客户基本信息、投保信息、健康档案的增删改查
- **FR-2**: 销售管理 - 销售线索、销售商机、合同订单、佣金结算管理
- **FR-3**: 档案生命周期管理 - 档案创建、归档、借阅、归还、销毁流程
- **FR-4**: 服务管理 - 服务工单创建、分配、处理、回访、评价全流程
- **FR-5**: 数据分析与报表 - 客户统计、销售业绩、服务质量、档案统计报表
- **FR-6**: 全局关键字查询 - 所有模块数据支持跨字段模糊搜索
- **FR-7**: 数据导出 - 所有查询结果支持Excel和PDF格式导出
- **FR-8**: 系统管理 - 用户、角色、权限、菜单、日志管理

## Non-Functional Requirements
- **NFR-1**: 系统响应时间 < 2秒，支持100并发用户
- **NFR-2**: 数据导出性能：10000条数据导出时间 < 30秒
- **NFR-3**: 支持RBAC权限控制，数据权限隔离
- **NFR-4**: 所有操作日志可审计，保留180天
- **NFR-5**: 前端界面响应式设计，支持主流浏览器

## Constraints
- **Technical**: 采用前后端分离架构，后端Java + Spring Boot，前端Vue.js + Element Plus
- **Business**: 项目开发周期8周，需符合保险行业数据安全规范
- **Dependencies**: MySQL数据库，Redis缓存，MinIO文件存储

## Assumptions
- 用户具备基本的计算机操作能力
- 部署环境已具备基础的网络和服务器资源
- 保险公司已具备基础的网络安全设施
- 业务流程符合现有保险监管要求

## Acceptance Criteria

### AC-1: 客户信息创建与查询
- **Given**: 管理员已登录系统
- **When**: 在客户管理模块创建客户档案，并使用关键字查询客户姓名
- **Then**: 客户信息成功保存，查询结果准确返回匹配的客户记录
- **Verification**: `programmatic`

### AC-2: 销售线索转化
- **Given**: 存在一条销售线索记录
- **When**: 将销售线索转化为商机并生成合同
- **Then**: 线索状态更新，商机创建成功，合同信息关联正确
- **Verification**: `programmatic`

### AC-3: 档案借阅流程
- **Given**: 存在已归档的客户档案
- **When**: 用户提交档案借阅申请并经审批通过
- **Then**: 档案状态变为已借出，借阅记录可追踪
- **Verification**: `programmatic`

### AC-4: 服务工单处理
- **Given**: 客户提交服务投诉工单
- **When**: 客服分配工单并处理完成
- **Then**: 工单状态更新为已完成，可查看处理记录和客户评价
- **Verification**: `programmatic`

### AC-5: 报表生成与展示
- **Given**: 系统存在业务数据
- **When**: 进入数据分析模块，选择时间范围生成报表
- **Then**: 报表图表正确渲染，数据统计准确
- **Verification**: `human-judgment`

### AC-6: 全局关键字搜索
- **Given**: 系统存在多条业务数据
- **When**: 在全局搜索框输入关键字"张三"
- **Then**: 返回所有模块中包含"张三"的相关记录，支持快速跳转
- **Verification**: `programmatic`

### AC-7: 数据导出功能
- **Given**: 查询结果列表有数据
- **When**: 点击导出按钮选择Excel/PDF格式
- **Then**: 文件成功下载，内容与查询结果一致
- **Verification**: `programmatic`

### AC-8: 权限控制
- **Given**: 普通用户与管理员用户账号
- **When**: 普通用户尝试访问系统管理模块
- **Then**: 访问被拒绝，提示权限不足
- **Verification**: `programmatic`
