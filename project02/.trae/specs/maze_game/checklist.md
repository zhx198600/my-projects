# 3D迷宫探险游戏 - 验证检查清单

## 迷宫生成与初始化验证
- [ ] 游戏启动后能正确生成15x15的迷宫
- [ ] 生成的迷宫是连通的（所有可通行格子相互可达）
- [ ] 玩家、怪物、3个宝藏、出口都放置在可通行格子上
- [ ] 玩家初始位置与怪物初始位置距离足够远（>5格）

## 视觉效果验证
- [ ] 所有游戏元素以伪3D效果呈现，有明显立体感
- [ ] 玩家形象为绿色，清晰可辨认
- [ ] 怪物形象为红色，清晰可辨认
- [ ] 宝藏为黄色，有明显发光效果
- [ ] 出口为深绿色，激活后清晰可见
- [ ] 墙壁有3D效果（顶面、侧面区分明显）
- [ ] 整体视觉风格统一，符合黑暗探索主题

## 视野与回声系统验证
- [ ] 默认状态下视野全黑，只能看到玩家所在格子
- [ ] 按空格键能触发回声定位
- [ ] 回声显示以玩家为中心3格范围内的所有格子（曼哈顿距离 <= 3）
- [ ] 回声显示持续1秒后恢复全黑
- [ ] 回声显示期间，宝藏有明显的发光动画效果
- [ ] 回声触发后有1秒冷却时间，期间无法再次触发

## 玩家移动控制验证
- [ ] 方向键（上/下/左/右）能正确控制玩家移动
- [ ] WASD键能正确控制玩家移动
- [ ] 玩家向墙壁方向移动时，位置不改变（无法穿墙）
- [ ] 玩家向可通行方向移动时，位置正确更新

## 怪物AI验证
- [ ] 回声未触发时，怪物每1秒随机移动一格
- [ ] 怪物随机移动时不会穿墙
- [ ] 玩家按空格触发回声后，怪物向玩家当前位置移动一格
- [ ] 怪物追踪时使用正确的寻路算法（最短路径）
- [ ] 怪物移动时如果路径被阻断，回退到随机移动

## 宝藏收集验证
- [ ] 玩家移动到宝藏格子时，宝藏被收集
- [ ] 收集宝藏后，宝藏计数正确增加
- [ ] 已收集的宝藏不再显示
- [ ] 收集第3个宝藏后，出口被激活（变为可见）

## 游戏胜负条件验证
- [ ] 玩家与怪物位置重合时，游戏状态变为"失败"
- [ ] 收集完3个宝藏前，玩家移动到出口位置不会触发胜利
- [ ] 收集完3个宝藏后，玩家移动到出口位置，游戏状态变为"胜利"
- [ ] 游戏胜利时显示"恭喜获胜！"信息
- [ ] 游戏失败时显示"游戏结束"信息

## UI界面验证
- [ ] 界面顶部有信息栏（深色半透明背景）
- [ ] 信息栏显示"宝藏: X/3"，数值随收集实时更新
- [ ] 信息栏显示当前游戏状态（进行中/胜利/失败）
- [ ] 信息栏文字清晰可读
- [ ] 游戏结束时有重新开始提示或功能

## 性能与稳定性验证
- [ ] 游戏运行流畅，帧率稳定在30FPS以上
- [ ] 输入响应及时（<100ms）
- [ ] 迷宫生成时间不超过1秒
- [ ] 长时间运行无崩溃或内存泄漏
- [ ] 游戏重新开始功能正常

## 整体游戏体验验证
- [ ] 游戏核心循环完整：开始 -> 探索 -> 收集宝藏 -> 找出口 -> 胜利
- [ ] 各系统协同工作正常（视野、回声、怪物AI、碰撞检测）
- [ ] 游戏难度适中，有一定挑战性
- [ ] 视觉效果美观大方，符合预期
