员工考勤管理系统 API 文档

版本: 1.0.0

描述: 员工考勤管理系统的 RESTful API 接口文档

认证方式: JWT Bearer Token，在请求头中添加: Authorization: Bearer {token}

API 接口

POST /api/auth/login 用户登录
请求体:
{
  "employee_no": "EMP001",
  "password": "123456"
}
响应示例:
{
  "success": true,
  "message": "登录成功",
  "data": {
    "token": "jwt_token_here",
    "user": {
      "id": 1,
      "name": "张三",
      "employee_no": "EMP001",
      "role": "管理员"
    }
  }
}
GET /api/auth/me 获取当前用户信息 需要认证
响应示例:
{
  "success": true,
  "message": "获取成功",
  "data": {
    "id": 1,
    "name": "张三",
    "employee_no": "EMP001",
    "role": "管理员"
  }
}
POST /api/system/backup 创建数据库备份 需要认证 仅管理员
响应示例:
{
  "success": true,
  "message": "数据库备份成功",
  "data": {
    "filename": "attendance_backup_20240101_120000.db"
  }
}
GET /api/system/backups 获取备份列表 需要认证 仅管理员
响应示例:
{
  "success": true,
  "message": "获取备份列表成功",
  "data": {
    "total": 2,
    "backups": [
      {
        "filename": "attendance_backup_20240101_120000.db",
        "size": 131072,
        "created_at": "2024-01-01 12:00:00"
      }
    ]
  }
}
GET /api/system/backup/{filename} 下载备份文件 需要认证 仅管理员
参数:
filename: 备份文件名
DELETE /api/system/backup/{filename} 删除备份文件 需要认证 仅管理员
响应示例:
{
  "success": true,
  "message": "删除备份文件成功"
}

更多接口

其他接口包括：

  • 部门管理: GET/POST/PUT/DELETE /api/departments
  • 员工管理: GET/POST/PUT/DELETE /api/employees
  • 考勤管理: POST /api/attendance/clock-in, clock-out, GET /api/attendance/status, history
  • 请假管理: POST/PUT /api/leave/request, GET /api/leave/my-requests
