# 安卓儿童绘本App - Product Requirement Document

## Overview
- **Summary**: 开发一款面向安卓移动端的儿童绘本阅读应用，实现绘本仿真翻页、图文展示、语音朗读和逐字高亮功能。应用内置示例绘本数据，通过系统TTS实现语音朗读，机器人吉祥物形象在朗读时提供互动体验。
- **Purpose**: 为儿童提供一个互动式、沉浸式的绘本阅读体验，通过语音朗读和逐字高亮帮助儿童识字和理解故事内容。
- **Target Users**: 3-10岁儿童及其家长

## Goals
- 实现流畅的仿真翻页绘本阅读体验
- 支持图文并茂的绘本内容展示
- 机器人吉祥物自动朗读绘本文字
- 逐字高亮显示正在朗读的文字
- 支持Android设备的良好兼容性

## Non-Goals (Out of Scope)
- 不开发iOS版本
- 不实现网络下载或在线购买绘本功能
- 不实现用户账户系统
- 不实现绘本编辑或创作功能
- 不实现社交分享功能

## Background & Context
- 这是一个全新的Flutter项目，从零开始构建
- 使用Android系统自带的TTS引擎进行语音朗读
- 绘本数据内置在应用assets目录中
- 需要支持仿真翻页效果，提供接近实体书的阅读体验

## Functional Requirements
- **FR-1**: 绘本列表展示
  - 展示可用的绘本封面和标题列表
  - 点击绘本进入阅读模式
- **FR-2**: 绘本阅读界面
  - 显示当前页面的图片和文字内容
  - 支持仿真翻页效果（从右向左翻页）
  - 显示当前页码和总页数
- **FR-3**: 机器人吉祥物展示
  - 界面固定位置显示可爱的机器人吉祥物形象
  - 朗读时机器人有简单的动画效果（如嘴巴张合）
- **FR-4**: 语音朗读功能
  - 翻页后自动开始朗读当前页面文字
  - 可手动控制播放/暂停
  - 使用Android系统TTS引擎
- **FR-5**: 逐字高亮功能
  - 文字默认显示为黑色
  - 朗读到某个字时，该字自动高亮为红色
  - 高亮与语音朗读同步

## Non-Functional Requirements
- **NFR-1**: 性能要求
  - 应用启动时间 < 3秒
  - 翻页动画流畅（60fps）
  - 语音启动延迟 < 500ms
- **NFR-2**: 兼容性要求
  - 支持Android API 21及以上版本
  - 适配不同屏幕尺寸（手机和平板）
- **NFR-3**: 用户体验
  - 界面简洁直观，适合儿童操作
  - 文字清晰易读，字号适中
  - 语音清晰，语速适中

## Constraints
- **Technical**: 
  - 使用Flutter框架开发
  - 使用Android系统TTS进行语音朗读
  - 仅支持Android平台
- **Business**: 
  - 项目周期：2周
  - 不依赖外部付费服务
- **Dependencies**: 
  - Flutter SDK >= 3.0.0
  - Android Studio for开发环境
  - 翻页效果可能需要使用第三方Flutter库

## Assumptions
- 用户设备已安装并启用了Android系统TTS引擎
- 用户设备支持中文语音输出
- 目标用户熟悉基本的触摸操作
- 绘本图片资源大小适中，不会造成内存问题

## Acceptance Criteria

### AC-1: 绘本列表展示
- **Given**: 应用已安装并启动
- **When**: 用户打开应用
- **Then**: 显示绘本列表，包含至少1本示例绘本的封面和标题
- **Verification**: `programmatic`
- **Notes**: 验证列表渲染正常，点击响应正确

### AC-2: 绘本阅读界面加载
- **Given**: 用户在绘本列表页面
- **When**: 用户点击某本绘本
- **Then**: 跳转到阅读界面，显示第一页内容（图片+文字）
- **Verification**: `programmatic`
- **Notes**: 验证图片和文字正确显示，位置布局合理

### AC-3: 仿真翻页效果
- **Given**: 用户正在阅读某页绘本
- **When**: 用户从右向左滑动（或点击右边缘）
- **Then**: 页面以仿真翻页动画切换到下一页
- **Verification**: `human-judgment`
- **Notes**: 验证翻页动画流畅自然，类似实体书效果

### AC-4: 机器人吉祥物显示
- **Given**: 用户在绘本阅读界面
- **When**: 页面加载完成
- **Then**: 界面固定位置（如右下角）显示机器人吉祥物形象
- **Verification**: `human-judgment`
- **Notes**: 验证机器人形象可爱、位置合理、不遮挡主要内容

### AC-5: 自动朗读功能
- **Given**: 用户刚翻到新的一页
- **When**: 页面内容加载完成
- **Then**: 自动开始朗读当前页面的文字内容，机器人有动画效果
- **Verification**: `programmatic`
- **Notes**: 验证TTS正常启动，声音清晰可闻

### AC-6: 手动控制朗读
- **Given**: 当前页面正在朗读或已暂停
- **When**: 用户点击播放/暂停按钮
- **Then**: 朗读状态切换（播放→暂停，或暂停→继续播放）
- **Verification**: `programmatic`
- **Notes**: 验证按钮状态与实际朗读状态一致

### AC-7: 文字默认黑色
- **Given**: 用户打开绘本阅读界面
- **When**: 尚未开始朗读或朗读未到达的文字
- **Then**: 所有文字显示为黑色
- **Verification**: `human-judgment`
- **Notes**: 验证文字颜色为标准黑色，对比度良好

### AC-8: 逐字高亮为红色
- **Given**: 系统正在朗读某段文字
- **When**: 朗读到某个字
- **Then**: 该字立即变为红色，之前已读过的字保持红色或其他区分色
- **Verification**: `programmatic`
- **Notes**: 验证高亮与语音同步，无明显延迟

### AC-9: 页码显示
- **Given**: 用户在阅读界面
- **When**: 查看屏幕
- **Then**: 显示当前页码/总页码（如 "3/10"）
- **Verification**: `programmatic`
- **Notes**: 验证页码随翻页正确更新

### AC-10: 返回绘本列表
- **Given**: 用户正在阅读某本绘本
- **When**: 用户点击返回按钮
- **Then**: 返回到绘本列表页面
- **Verification**: `programmatic`
- **Notes**: 验证返回后列表状态正常
