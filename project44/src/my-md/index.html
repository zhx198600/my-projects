项目介绍

本项目是一个轻量级、响应式的展示型网页模板，支持 Markdown 直接渲染，无需编写复杂 HTML 代码。

特点： - 简洁美观，阅读舒适 - 支持移动端自适应 - 代码高亮、表格、图片完美展示 - 可一键导出为静态 HTML 网页

功能特性

  • ✅ Markdown 实时预览
  • ✅ 代码块语法高亮
  • ✅ 图片自适应排版
  • ✅ 多级标题与目录
  • ✅ 表格、列表、引用样式统一
  • ✅ 支持 Emoji 表情增强表现力

使用说明

  1. 编辑本文档，替换成你自己的内容
  2. 使用支持导出网页的编辑器（Typora / VS Code 插件）
  3. 选择「导出 → HTML」
  4. 得到可直接打开、上传服务器的网页文件
