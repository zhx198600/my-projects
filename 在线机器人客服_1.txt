## 技术栈

### 前端 (client/)
- **框架**: Vite + React + TypeScript
- **依赖**: 
  - react, react-dom (基础)
  - react-router-dom (路由)
  - socket.io-client (WebSocket 客户端)
  - axios (HTTP 客户端)
- **默认端口**: 5173

### 后端 (server/)
- **框架**: Node.js + Express + TypeScript
- **依赖**:
  - express (Web 框架)
  - cors (跨域支持)
  - socket.io (WebSocket 服务端)
  - sql.js (SQLite 数据库，纯 JavaScript 实现，无需编译)
- **开发依赖**: typescript, @types/node, @types/express, @types/cors, ts-node, nodemon
- **默认端口**: 3001

新增了以下类型：

- `IntentService` - 意图服务接口
- `ProcessMessageResult` - 消息处理结果

### 2. 意图服务实现

**文件**: `src/services/intentService.ts`

实现了 `IntentServiceClass` 类，包含以下核心方法：

| 方法 | 功能 |
|------|------|
| `preprocess()` | 消息预处理：转小写、去除两端空白 |
| `tokenize()` | 简单分词：按空格、标点分割 |
| `parseKeywords()` | 解析逗号分隔的关键词字符串 |
| `match()` | 计算消息与知识库的匹配度，返回最佳匹配 |
| `getDefaultReply()` | 获取兜底回复 |
| `processMessage()` | 处理用户消息，返回最终回复 |

**匹配算法逻辑**：
1. 将用户消息分词
2. 遍历所有知识库条目
3. 计算消息分词与条目标题词的包含匹配
4. 匹配度 = (匹配关键词数量) / (总关键词数量)
5. 返回匹配度最高的条目（> 0 时），否则返回 null
