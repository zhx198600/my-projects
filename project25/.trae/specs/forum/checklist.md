# 本地生活论坛网站 - 验证清单

## 核心功能验证
- [x] 游客无需登录即可浏览所有帖子和评论内容
- [x] 用户可以注册新账号并成功登录
- [x] 登录用户可以发布新帖子
- [x] 帖子可以按政治、经济、科技、民生分类筛选
- [x] 用户可以对帖子发表一级评论
- [x] 用户可以对已有评论进行回复（支持多层嵌套）
- [x] 评论内容中的Markdown语法可以正确渲染
- [x] 管理员可以通过用户名密码登录后台

## 管理员权限验证
- [x] 管理员可以在后台查看所有帖子列表
- [x] 管理员可以删除帖子（包含该帖子下的所有评论）
- [x] 管理员可以在后台查看所有评论列表
- [x] 管理员可以删除单条评论（包含其子评论）
- [x] 管理员可以设置帖子禁止/允许评论状态
- [x] 禁止评论的帖子普通用户无法发表新评论
- [x] 管理员可以添加、删除敏感词
- [x] 包含敏感词的帖子/评论发布时被拦截并提示

## 安全与权限验证
- [x] 未登录用户无法发布帖子和评论
- [x] 普通用户无法访问管理员后台
- [x] 普通用户无法调用管理员专属API
- [x] 用户密码在数据库中加密存储
- [x] JWT Token过期后需要重新登录
- [x] Markdown渲染有XSS防护，不会执行危险脚本

## 用户体验验证
- [x] 页面响应时间小于2秒
- [x] 分类切换时页面无明显卡顿
- [x] 评论嵌套层级显示清晰，缩进正确
- [x] 后台管理界面布局清晰，操作直观
- [x] 移动端显示正常，响应式布局适配
- [x] 删除操作有二次确认提示
- [x] 敏感词拦截有明确友好的错误提示

## 数据完整性验证
- [x] 删除帖子时，帖子下所有评论一并删除
- [x] 删除评论时，其子评论一并删除
- [x] 用户信息修改后数据库同步更新
- [x] 敏感词修改后立即在内容检测中生效
- [x] 所有操作日志可追溯
