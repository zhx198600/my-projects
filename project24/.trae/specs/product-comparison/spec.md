# 商品比价网站 - Product Requirement Document

## Overview
- **Summary**: 构建一个Web应用，用户输入至少两个电商商品详情页链接，系统自动抓取并提取产品参数、价格、用户评价等信息，基于用户选择的关注点（性价比、外观、质量、功能等）进行多维度对比分析，最终给出智能化购买建议。
- **Purpose**: 解决消费者在网购时需要手动对比多个平台商品参数、评价的痛点，提供自动化、数据驱动的购买决策支持。
- **Target Users**: 网购消费者、比价需求用户、购买决策辅助者

## Goals
- 支持输入至少2个商品详情页URL进行对比
- 自动抓取解析商品核心参数（价格、品牌、型号等）
- 提取并分析用户评价数据
- 提供多维度对比可视化展示
- 基于用户关注点给出智能化购买建议

## Non-Goals (Out of Scope)
- 不实现实时价格监控和提醒功能
- 不支持超过5个商品同时对比
- 不提供直接购买跳转和订单跟踪
- 不覆盖所有电商平台（初期支持主流平台）
- 不实现用户账号系统和历史记录

## Background & Context
- 现代电商平台众多，消费者做购买决策需要花费大量时间对比
- 手动整理参数和阅读大量评价效率低下
- 需要一个自动化工具来辅助购买决策过程

## Functional Requirements
- **FR-1**: 用户可以输入2-5个商品详情页URL
- **FR-2**: 系统自动抓取并解析商品基础信息（标题、价格、品牌、图片）
- **FR-3**: 系统提取并结构化展示商品技术参数
- **FR-4**: 系统爬取用户评价并进行情感分析统计
- **FR-5**: 用户可选择对比侧重点（性价比、外观、质量、功能、口碑）
- **FR-6**: 系统生成多维度对比表格和可视化图表
- **FR-7**: 系统基于用户关注点输出最终购买建议和理由

## Non-Functional Requirements
- **NFR-1**: 页面响应时间 < 2秒，数据抓取处理 < 15秒
- **NFR-2**: 主流电商平台解析成功率 > 80%
- **NFR-3**: 移动端自适应响应式设计
- **NFR-4**: 界面简洁直观，操作流程不超过3步

## Constraints
- **Technical**: 使用Node.js + Vue/React技术栈，前后端分离架构
- **Business**: 免费开源工具，不涉及商业数据授权
- **Dependencies**: 使用网页爬虫库、NLP情感分析库、前端图表库

## Assumptions
- 电商网站页面结构相对稳定，反爬机制可绕过
- 用户输入的URL为有效商品详情页链接
- 网络环境可正常访问目标电商网站

## Acceptance Criteria

### AC-1: URL输入功能
- **Given**: 用户访问比价网站首页
- **When**: 用户在输入框中输入2个有效URL并提交
- **Then**: 系统接收URL并进入处理状态，显示加载动画
- **Verification**: `programmatic`
- **Notes**: 验证表单验证逻辑和加载状态显示

### AC-2: 商品信息抓取解析
- **Given**: 用户提交了有效的商品URL
- **When**: 系统完成页面抓取处理
- **Then**: 成功提取并展示商品标题、价格、品牌、主图
- **Verification**: `programmatic`
- **Notes**: 验证主流平台（京东、淘宝、天猫）解析成功率

### AC-3: 参数结构化对比
- **Given**: 系统已解析完成多个商品
- **When**: 用户查看参数对比页面
- **Then**: 参数以表格形式对比展示，相同参数合并，差异参数高亮
- **Verification**: `human-judgment`
- **Notes**: 验证参数结构化展示的清晰度和可读性

### AC-4: 用户评价分析展示
- **Given**: 系统已获取用户评价数据
- **When**: 用户切换到评价分析标签
- **Then**: 展示好评率、关键词云、正面负面评价摘要
- **Verification**: `programmatic`
- **Notes**: 验证评价统计数据的准确性和可视化效果

### AC-5: 关注点选择和建议生成
- **Given**: 所有商品数据已准备完成
- **When**: 用户选择"性价比"作为主要关注点并生成建议
- **Then**: 系统计算性价比得分，给出明确的购买建议TOP1及详细理由
- **Verification**: `human-judgment`
- **Notes**: 验证建议逻辑的合理性和可解释性

### AC-6: 响应式界面设计
- **Given**: 用户使用不同设备访问
- **When**: 使用桌面端、平板、手机屏幕访问
- **Then**: 界面自适应调整，所有功能正常可用
- **Verification**: `human-judgment`
