# PPT智能生成系统 - 验证清单

## 核心功能验证

### 内容输入与解析
- [ ] 支持上传.doc格式的Word文档并成功解析
- [ ] 支持上传.docx格式的Word文档并成功解析
- [ ] 上传非Word文件时返回明确的错误提示
- [ ] 上传超大文件（超过限制）时返回明确的错误提示
- [ ] 支持直接在文本框中输入多行文本
- [ ] 支持从剪贴板粘贴文本内容
- [ ] 两种输入方式可正常切换
- [ ] 解析后的内容预览与原始文档完全一致（逐字比对）

### 内容完整性保护（核心约束）
- [ ] Word解析后的文本与原始文档文字内容100%一致
- [ ] 文本输入的内容被完整保存，无任何修改
- [ ] 分页后的所有页面内容拼接与原始内容完全一致
- [ ] 页面合并/拆分操作后，所有内容保持完整
- [ ] 任何调整操作后，内容哈希校验通过
- [ ] 导出的PDF中文字内容与原始输入完全一致
- [ ] 前端界面显示"内容已保护"状态提示

### 内容分析与分页
- [ ] 长文本被自动划分为多个逻辑页面
- [ ] 每页内容量适中（不出现过长或过短的页面）
- [ ] 分页不会截断完整的句子或段落
- [ ] 标题被正确识别并放在页面顶部
- [ ] 列表项被正确识别和展示
- [ ] 每个页面都提取到非空的关键词列表
- [ ] 提供页面缩略图导航
- [ ] 点击缩略图可跳转到对应页面
- [ ] 上一页/下一页导航功能正常
- [ ] 当前页码显示正确

### 页面调整功能

- [ ] 多次合并/拆分操作后，内容仍保持完整
- [ ] 调整后的页面缩略图正确更新

### 排版布局
- [ ] 提供至少3种不同的排版模板
- [ ] 标题页模板正确展示标题和副标题

- [ ] 列表页模板正确展示标题和列表项
- [ ] 图片+文字页模板正确实现图文混排
- [ ] 字体大小根据内容长度自动调整
- [ ] 文字清晰可读，无溢出或截断
- [ ] 配色方案协调统一
- [ ] 整体风格专业美观

### AI插图生成

- [ ] 为每个页面生成2-3张候选插图
- [ ] 生成的插图与页面内容主题相关

### 在线预览

### PDF导出
