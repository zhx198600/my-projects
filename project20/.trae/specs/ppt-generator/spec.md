# PPT智能生成系统 - Product Requirement Document

## Overview
- **Summary**: 构建一个智能PPT生成系统，用户可通过上传Word文档或直接输入文本内容，系统将自动分析内容结构、智能排版、自动生成匹配的精美插图，最终生成可在线预览和导出为PDF格式的演示文稿。核心原则：**不修改用户原始文字内容，仅调整排版布局**。

- **Purpose**: 解决用户手动制作PPT耗时费力的痛点，通过AI自动化技术将文本内容快速转化为专业美观的演示文稿，大幅提升工作效率。

- **Target Users**: 
  - 需要快速制作演示文稿的商务人士
  - 需要准备教学课件的教师
  - 需要整理报告的学生
  - 任何需要将文本内容可视化展示的用户

## Goals
1. 支持Word文档上传和直接文本输入两种内容获取方式
2. 精准提取并保留用户原始文字内容，不作任何修改
3. 智能分析内容结构，自动划分PPT页面
4. 提供精美且专业的排版布局
5. 根据内容自动生成匹配的精美插图
6. 支持PPT在线实时预览
7. 支持导出为PDF格式

## Non-Goals (Out of Scope)
- 不会修改用户提供的任何文字内容（包括语法、用词、句子结构等）
- 不支持用户手动编辑PPT内容（仅允许调整排版和选择插图）
- 不支持导出为PPTX原生格式（本次仅支持HTML预览和PDF导出）
- 不支持多人协作编辑
- 不支持自定义主题模板（本次采用预设专业模板）

## Background & Context
- 手动制作PPT是一项耗时的工作，平均制作一页专业PPT需要15-30分钟
- 用户通常已有文字内容（Word文档或草稿），但缺乏设计能力将其转化为精美的演示文稿
- AI图像生成技术的成熟使得根据文本内容自动生成匹配插图成为可能
- 现有PPT生成工具往往会过度修改用户内容，或生成质量参差不齐

## Functional Requirements

### 内容输入模块
- **FR-1**: 支持Word文档（.doc, .docx）上传并解析其中的文本内容
- **FR-2**: 支持用户直接在文本框中输入或粘贴文本内容
- **FR-3**: 支持两种输入方式的切换，优先使用最新输入的内容
- **FR-4**: 展示解析后的原始内容预览，供用户确认

### 内容分析与结构识别
- **FR-5**: 智能分析文本内容结构，识别标题、段落、列表等元素
- **FR-6**: 根据内容长度和逻辑结构自动划分PPT页面
- **FR-7**: 允许用户调整页面划分方式（合并/拆分页面）
- **FR-8**: 为每一页提取关键词，用于后续插图生成

### 排版布局引擎
- **FR-9**: 提供多种预设的专业排版模板
- **FR-10**: 根据页面内容类型（标题页、内容页、列表页等）自动选择最合适的排版
- **FR-11**: 确保文字清晰可读，自动调整字体大小和行间距
- **FR-12**: 保持统一的设计风格和配色方案

### AI插图生成
- **FR-13**: 为每一页PPT根据关键词和内容描述生成匹配的精美插图
- **FR-14**: 支持为单页PPT提供多张候选插图供用户选择
- **FR-15**: 支持用户重新生成特定页面的插图
- **FR-16**: 确保插图风格与整体PPT风格保持一致

### 在线预览
- **FR-17**: 提供幻灯片模式预览（单页全屏显示）
- **FR-18**: 提供缩略图导航，支持快速跳转到任意页面
- **FR-19**: 支持上一页/下一页导航
- **FR-20**: 预览页面实时反映用户对排版和插图的调整

### 导出功能
- **FR-21**: 支持将整个PPT导出为PDF格式
- **FR-22**: 确保PDF导出质量与在线预览一致
- **FR-23**: 支持自定义PDF导出选项（页面大小、质量等）

## Non-Functional Requirements

### 性能
- **NFR-1**: 页面加载时间 < 3秒
- **NFR-2**: Word文档解析时间 < 5秒（10页文档内）
- **NFR-3**: PPT生成时间 < 10秒（不含AI插图生成）
- **NFR-4**: AI插图生成时间 < 30秒/页（可显示进度）

### 可靠性
- **NFR-5**: 系统可用性 > 99%
- **NFR-6**: 文件上传成功率 > 99%
- **NFR-7**: PDF导出成功率 > 99%

### 安全性
- **NFR-8**: 所有文件上传需进行病毒扫描（或限制文件类型）
- **NFR-9**: 用户上传的文档在处理完成后24小时内自动删除
- **NFR-10**: 不存储用户的敏感信息

### 兼容性
- **NFR-11**: 支持主流浏览器：Chrome、Firefox、Safari、Edge（最新两个版本）
- **NFR-12**: 支持桌面端和平板端访问
- **NFR-13**: 导出的PDF兼容Adobe Reader和其他主流PDF阅读器

## Constraints

### Technical
- **前端框架**: React 18+
- **后端框架**: Node.js + Express
- **Word解析**: 使用mammoth.js或类似库
- **PDF生成**: 使用puppeteer或类似无头浏览器方案
- **AI图像生成**: 集成OpenAI DALL-E或Stable Diffusion API
- **部署**: 支持Docker容器化部署

### Business
- **开发周期**: 预计4周完成MVP版本
- **成本控制**: AI图像生成API调用成本需计入系统成本
- **合规性**: 需遵守数据保护相关法规

### Dependencies
- **外部API**: AI图像生成服务（DALL-E/Stable Diffusion）
- **第三方库**: mammoth.js、puppeteer、react-router等

## Assumptions
- 用户上传的Word文档主要包含文本内容，复杂格式（如表格、图片）可能无法完全解析
- AI图像生成API可用且成本可控
- 网络连接稳定，可正常调用外部AI服务
- 用户对"不修改文字内容"有清晰预期，即保持原文的每个字和标点符号

## Acceptance Criteria

### AC-1: Word文档上传与解析
- **Given**: 用户有一个.doc或.docx格式的Word文档
- **When**: 用户上传该文档
- **Then**: 系统成功解析文档中的所有文本内容，并在界面上显示解析结果供用户确认
- **Verification**: `programmatic`
- **Notes**: 验证解析结果与原始文档的文字内容完全一致

### AC-2: 直接文本输入
- **Given**: 用户有一段需要制作成PPT的文本内容
- **When**: 用户将文本内容粘贴或输入到文本框中
- **Then**: 系统接收并保存用户输入的内容，可预览输入的文本
- **Verification**: `programmatic`
- **Notes**: 验证输入的文本被完整保存，无任何修改

### AC-3: 内容完整性保护
- **Given**: 用户已通过任意方式输入内容
- **When**: 系统生成PPT的整个过程中
- **Then**: 用户提供的所有文字内容保持完全不变，包括每个字、标点符号、段落结构
- **Verification**: `programmatic`
- **Notes**: 这是核心约束，必须严格验证

### AC-4: 智能页面划分
- **Given**: 用户有一段较长的文本内容
- **When**: 系统分析内容结构
- **Then**: 系统根据内容逻辑和长度自动将内容划分为多个PPT页面，每页内容完整且逻辑连贯
- **Verification**: `programmatic` + `human-judgment`
- **Notes**: 程序验证划分算法正确性，人工验证划分合理性

### AC-5: 页面调整功能
- **Given**: 系统已自动划分好PPT页面
- **When**: 用户选择合并相邻页面或拆分某一页面
- **Then**: 系统按照用户操作调整页面结构，保持所有文字内容完整
- **Verification**: `programmatic`

### AC-6: 智能排版布局
- **Given**: 每个PPT页面有相应的内容
- **When**: 系统应用排版
- **Then**: 系统根据页面内容类型自动选择合适的排版模板，确保文字清晰可读、布局美观专业
- **Verification**: `human-judgment`
- **Notes**: 评估排版的美观度、可读性和专业性

### AC-7: AI插图生成
- **Given**: 某一页PPT有明确的内容和关键词
- **When**: 系统调用AI生成插图
- **Then**: 生成1-3张与页面内容主题相关的精美插图，插图风格与整体PPT协调
- **Verification**: `programmatic` + `human-judgment`
- **Notes**: 程序验证插图成功生成，人工评估插图与内容的相关性和美观度

### AC-8: 插图选择与重新生成
- **Given**: 某一页有候选插图
- **When**: 用户选择不同插图或点击重新生成
- **Then**: 系统立即更新该页面的插图，或调用AI重新生成新的候选插图
- **Verification**: `programmatic`

### AC-9: 幻灯片模式预览
- **Given**: PPT已生成完成
- **When**: 用户点击预览按钮
- **Then**: 系统进入幻灯片预览模式，单页全屏显示当前页面，可通过上一页/下一页导航
- **Verification**: `programmatic`

### AC-10: 缩略图导航
- **Given**: 多页PPT
- **When**: 用户在预览界面
- **Then**: 侧边栏显示所有页面的缩略图，点击任意缩略图可立即跳转到对应页面
- **Verification**: `programmatic`

### AC-11: 实时更新预览
- **Given**: 用户正在调整排版或更换插图
- **When**: 用户完成调整操作
- **Then**: 预览界面立即反映最新的调整结果，无需刷新页面
- **Verification**: `programmatic`

### AC-12: PDF导出功能
- **Given**: PPT已生成并预览满意
- **When**: 用户点击导出PDF按钮
- **Then**: 系统生成PDF文件并提供下载，PDF内容与在线预览完全一致
- **Verification**: `programmatic`
- **Notes**: 验证PDF可正常打开，内容与预览一致

### AC-13: 响应式设计
- **Given**: 用户使用不同设备访问
- **When**: 用户在桌面端或平板端打开系统
- **Then**: 界面自适应不同屏幕尺寸，保持良好的用户体验
- **Verification**: `human-judgment`

### AC-14: 性能要求
- **Given**: 正常使用场景
- **When**: 用户执行关键操作
- **Then**: 
  - 页面加载 < 3秒
  - Word解析（10页内）< 5秒
  - PPT生成 < 10秒
  - 每页插图生成显示进度，< 30秒/页
- **Verification**: `programmatic`
