# 移动端H5学科作业助手 - Product Requirement Document

## Overview

- **Summary**: 构建一个移动端H5学科作业助手网站，支持K12学生上传数学、语文、英语、生物、化学、物理作业图片，AI引导孩子一步步思考解题，全程配备趣味配图、音效和鼓励话语，完成后提供同类型题目巩固练习，并支持错题记录导出功能。
- **Purpose**: 通过AI引导式教学而非直接给出答案，培养孩子独立思考能力，让学习过程更有趣，同时帮助家长和老师跟踪学习进度。
- **Target Users**: 6-18岁K12学生、学生家长、家庭辅导老师

## Goals

- 支持6大学科作业图片上传和多题目识别
- AI分步引导解题，培养独立思考能力
- 通过音效、配图和鼓励话语提升学习兴趣
- 智能生成同类型练习题进行巩固
- 错题本记录和导出功能

## Non-Goals (Out of Scope)

- 不开发原生App，仅提供H5版本
- 不支持手写实时答题，仅支持图片上传
- 不做用户账号系统和付费功能
- 不做老师端班级管理
- 不支持视频讲解和直播功能

## Background & Context

- 当前市面上作业助手多直接给出答案，不利于培养孩子思考能力
- 移动端H5无需下载，触达率高
- 游戏化元素（音效、配图、鼓励）能显著提升低龄孩子学习动力
- 错题本是学习过程中最有效的工具之一

## Functional Requirements

- **FR-1**: 支持上传作业图片，自动识别图片中的题目数量
- **FR-2**: 支持数学、语文、英语、生物、化学、物理6大学科
- **FR-3**: AI分步骤引导孩子思考，每步给出提示而非直接答案
- **FR-4**: 解题过程中随机展示趣味配图和播放音效
- **FR-5**: 每步完成后展示鼓励性话语
- **FR-6**: 题目完成后一键生成3/5道同类型巩固练习题
- **FR-7**: 自动记录做错的题目到错题本
- **FR-8**: 支持错题记录导出为PDF格式

## Non-Functional Requirements

- **NFR-1**: 移动端响应式设计，适配iOS和Android主流机型
- **NFR-2**: 图片上传处理时间 < 5秒
- **NFR-3**: 首屏加载时间 < 2秒
- **NFR-4**: PWA支持，可添加到桌面
- **NFR-5**: 图片识别准确率 > 85%

## Constraints

- **Technical**: 纯前端H5，使用Vue.js或React框架
- **Business**: 2周内完成MVP版本
- **Dependencies**: 需要OCR和大语言模型API支持

## Assumptions

- 用户设备有网络连接
- 作业图片清晰可识别
- 用户使用现代手机浏览器

## Acceptance Criteria

### AC-1: 作业图片上传

- **Given**: 用户在移动端打开网站
- **When**: 用户点击上传按钮选择或拍摄作业图片
- **Then**: 图片成功上传并显示预览，系统自动识别题目数量并提示用户确认
- **Verification**: `programmatic`

### AC-2: 多题目选择

- **Given**: 图片上传成功，识别出多个题目
- **When**: 用户勾选想要解答的题目
- **Then**: 系统展示选中的题目列表，用户点击开始解题
- **Verification**: `programmatic`

### AC-3: AI分步引导解题

- **Given**: 用户进入某道题的解题流程
- **When**: 用户阅读当前步骤提示并完成思考
- **Then**: 可以点击"下一步"继续引导，直到最终得出答案
- **Verification**: `programmatic`

### AC-4: 趣味配图展示

- **Given**: 解题过程中的任意步骤
- **When**: 步骤加载完成
- **Then**: 随机展示与学科相关的趣味配图（如数学符号卡通化、实验场景等）
- **Verification**: `human-judgment`

### AC-5: 音效播放

- **Given**: 用户进行点击下一步、答对、完成题目等操作
- **When**: 触发相应事件
- **Then**: 播放对应的积极音效
- **Verification**: `human-judgment`

### AC-6: 鼓励性话语

- **Given**: 用户每完成一个解题步骤
- **When**: 点击"明白了，继续"
- **Then**: 显示随机鼓励话语（如"太棒了！"、"你真聪明！"、"继续加油！"等）
- **Verification**: `programmatic`

### AC-7: 同类型练习题生成

- **Given**: 用户完成一道题的解答
- **When**: 用户点击"生成练习题"按钮并选择3道或5道
- **Then**: 系统展示对应数量的同类型题目
- **Verification**: `programmatic`

### AC-8: 错题自动记录

- **Given**: 用户在解题过程中选择"我做错了"
- **When**: 题目完成后
- **Then**: 该题目自动加入错题本
- **Verification**: `programmatic`

### AC-9: 错题导出

- **Given**: 用户有多条错题记录
- **When**: 用户在错题本页面点击"导出"按钮
- **Then**: 错题记录以PDF格式下载到用户设备
- **Verification**: `programmatic`

### AC-10: 移动端适配

- **Given**: 用户使用任意主流手机访问网站
- **When**: 在不同屏幕尺寸下浏览所有页面
- **Then**: 布局正常，无元素溢出，按钮大小适合触控
- **Verification**: `human-judgment`
