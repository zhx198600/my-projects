# 图片处理网站 - Product Requirement Document

## Overview
- **Summary**: 构建一个功能完善的在线图片处理网站，支持图片上传、裁剪、旋转、AI 抠图、换背景等核心功能。采用原生 HTML/CSS/JavaScript 实现前端 SPA 架构，后端使用 Node.js + Express 提供 API 服务。
- **Purpose**: 提供一个用户友好的在线图片编辑工具，让用户无需安装专业软件即可完成常见的图片处理操作。
- **Target Users**: 普通用户、设计师、社交媒体内容创作者等需要快速处理图片的人群。

## Goals
- 实现图片上传功能，支持本地文件上传和预览
- 实现图片裁剪功能，支持自由调整裁剪区域和固定比例裁剪
- 实现图片旋转功能，支持 90 度旋转和任意角度旋转
- 实现 AI 抠图功能（模拟实现），自动识别并分离主体与背景
- 实现换背景功能，支持将抠图结果替换为纯色或新的背景图片
- 提供实时预览功能，让用户在操作时即时看到效果
- 支持处理后的图片下载

## Non-Goals (Out of Scope)
- 不实现图片滤镜、调整亮度/对比度等高级图片编辑功能
- 不实现图层管理功能
- 不实现图片格式批量转换功能
- 不实现用户账户和图片存储功能（处理后的图片仅保存在本地）
- 不实现真实的 AI 模型（AI 抠图使用模拟实现）

## Background & Context
- 在线图片处理工具市场需求旺盛，但大多数免费工具功能有限或带有水印
- 本项目将提供一个简洁、功能聚焦的图片处理工具
- 使用原生 JavaScript 实现，确保轻量、快速加载
- 采用 Canvas API 进行客户端图片处理，减少服务器压力

## Functional Requirements
- **FR-1**: 图片上传与预览
  - 用户可通过拖拽或点击上传本地图片文件
  - 支持常见图片格式（JPG、PNG、WebP）
  - 上传后立即显示原图预览
  - 显示图片基本信息（尺寸、大小、格式）
- **FR-2**: 图片裁剪
  - 提供交互式裁剪框，可拖拽调整大小和位置
  - 支持自由比例裁剪和常用固定比例裁剪（1:1, 4:3, 16:9 等）
  - 实时预览裁剪效果
  - 确认裁剪后更新图片
- **FR-3**: 图片旋转
  - 支持 90 度顺时针/逆时针旋转按钮
  - 支持 180 度旋转
  - 支持滑块或输入框进行任意角度旋转
  - 实时预览旋转效果
- **FR-4**: AI 抠图（模拟）
  - 用户点击"AI 抠图"按钮触发抠图功能
  - 模拟 AI 处理过程（显示加载动画）
  - 提供模拟的抠图效果（使用简单的算法或预设轮廓）
  - 显示处理进度和完成提示
- **FR-5**: 背景替换
  - 在抠图完成后，支持背景替换
  - 提供预设纯色背景选项
  - 支持上传自定义背景图片
  - 实时预览背景替换效果
- **FR-6**: 图片导出与下载
  - 支持导出为 PNG、JPG、WebP 格式
  - 支持选择导出质量
  - 一键下载处理后的图片
- **FR-7**: 操作历史与撤销/重做
  - 记录用户操作历史
  - 支持撤销（Undo）和重做（Redo）功能
  - 重置按钮：一键恢复到原始图片
- **FR-8**: 响应式布局
  - 适配桌面端和移动端不同屏幕尺寸
  - 在移动端提供优化的操作界面

## Non-Functional Requirements
- **NFR-1**: 性能
  - 图片上传后 2 秒内完成加载和预览
  - 裁剪、旋转操作响应时间 < 200ms
  - AI 抠图模拟过程显示进度，总耗时控制在 2-3 秒（模拟真实 AI 处理体验）
- **NFR-2**: 安全性
  - 所有图片处理在客户端完成，不上传到服务器（除背景图片上传）
  - 不存储用户上传的图片到服务器，保护用户隐私
- **NFR-3**: 兼容性
  - 支持主流现代浏览器（Chrome、Firefox、Safari、Edge 最新两个主要版本）
  - 支持的图片格式：JPEG, PNG, WebP, BMP
- **NFR-4**: 用户体验
  - 界面简洁直观，操作指引清晰
  - 所有操作提供即时视觉反馈
  - 错误提示友好，帮助用户解决问题

## Constraints
- **Technical**:
  - 前端：原生 HTML5, CSS3, ES6+ JavaScript（不使用框架）
  - 后端：Node.js + Express
  - 图片处理主要使用 HTML5 Canvas API
- **Business**:
  - 纯前端实现主要功能，后端仅提供简单的静态文件服务
  - AI 抠图使用模拟实现，不依赖真实 AI 模型
- **Dependencies**:
  - 无需额外的前端框架（如 React/Vue）
  - 仅使用原生浏览器 API

## Assumptions
- 用户已安装现代浏览器（支持 ES6+ 和 Canvas API）
- 用户上传的图片大小在合理范围内（建议 < 10MB）
- 网络连接稳定（如果有背景图片上传功能）

## Acceptance Criteria

### AC-1: 图片上传功能
- **Given**: 用户在浏览器中打开网站
- **When**: 用户通过拖拽或点击选择器上传一张图片
- **Then**: 
  1. 图片成功加载并显示在预览区域
  2. 显示图片的基本信息（尺寸、大小、格式）
  3. 所有编辑功能按钮变为可用状态
- **Verification**: `programmatic`
- **Notes**: 测试不同格式（JPG, PNG, WebP）和不同大小的图片

### AC-2: 图片裁剪功能
- **Given**: 已上传一张图片，处于编辑状态
- **When**: 用户点击"裁剪"工具，调整裁剪框大小和位置，然后确认裁剪
- **Then**:
  1. 裁剪框可自由拖拽调整大小和位置
  2. 选择固定比例时，裁剪框保持对应比例
  3. 确认裁剪后，图片显示裁剪后的结果
  4. 裁剪操作可通过"撤销"按钮恢复
- **Verification**: `programmatic`

### AC-3: 图片旋转功能
- **Given**: 已上传一张图片，处于编辑状态
- **When**: 用户点击旋转按钮（90度顺时针/逆时针）或使用滑块调整角度
- **Then**:
  1. 点击 90 度按钮时，图片立即旋转对应角度
  2. 使用滑块时，图片实时跟随角度变化
  3. 旋转后的图片保持正确的宽高比例
  4. 旋转操作可通过"撤销"按钮恢复
- **Verification**: `programmatic`

### AC-4: AI 抠图（模拟）功能
- **Given**: 已上传一张图片，处于编辑状态
- **When**: 用户点击"AI 抠图"按钮
- **Then**:
  1. 显示处理中动画和进度提示
  2. 模拟处理过程持续 2-3 秒
  3. 完成后显示抠图结果（主体保留，背景透明或被标记）
  4. 背景替换功能变为可用状态
- **Verification**: `programmatic`
- **Notes**: 验证模拟抠图效果是否正确显示

### AC-5: 背景替换功能
- **Given**: 已完成 AI 抠图，背景透明
- **When**: 用户选择一个预设颜色或上传一张背景图片
- **Then**:
  1. 选择预设颜色时，背景立即变为该颜色
  2. 上传背景图片时，新背景图片显示在主体后面
  3. 背景替换效果可实时预览
  4. 背景替换操作可通过"撤销"按钮恢复
- **Verification**: `programmatic`

### AC-6: 图片导出与下载功能
- **Given**: 用户已完成图片编辑操作
- **When**: 用户选择导出格式（PNG/JPG/WebP）和质量，然后点击"下载"
- **Then**:
  1. 生成处理后的图片
  2. 触发浏览器下载对话框
  3. 下载的文件格式与选择的一致
  4. JPG/WebP 格式的图片质量符合选择的设置
- **Verification**: `programmatic`
- **Notes**: 验证 PNG 格式保留透明度

### AC-7: 撤销/重做与重置功能
- **Given**: 用户已执行多个编辑操作
- **When**: 用户点击"撤销"、"重做"或"重置"按钮
- **Then**:
  1. 点击"撤销"时，恢复到上一步操作前的状态
  2. 点击"重做"时，恢复已撤销的操作
  3. 点击"重置"时，恢复到原始图片状态
  4. 无操作可撤销/重做时，对应按钮变为禁用状态
- **Verification**: `programmatic`

### AC-8: 响应式布局
- **Given**: 用户在不同设备上访问网站
- **When**: 用户在桌面端（> 1024px）和移动端（< 768px）分别打开网站
- **Then**:
  1. 桌面端显示完整的工具栏和编辑区域
  2. 移动端工具栏适配屏幕宽度，按钮大小合适
  3. 编辑区域在移动端可正常操作
  4. 所有功能在移动端可用
- **Verification**: `human-judgment`

### AC-9: 后端服务启动
- **Given**: 项目代码已完整
- **When**: 用户执行 `npm install` 然后 `npm start`
- **Then**:
  1. 依赖安装成功无错误
  2. 服务器启动成功，监听指定端口（如 3000）
  3. 访问 `http://localhost:3000` 可正常打开网站
- **Verification**: `programmatic`
