# 香港地铁实时大屏监测系统 - Product Requirement Document

## Overview
- **Summary**: 构建一个高分辨率的香港地铁实时大屏监测系统，在轨道图上可视化展示实时运行的地铁车辆，支持车次信息悬浮展示和实时数据刷新。
- **Purpose**: 提供直观的地铁运营状态监控界面，帮助运营人员和乘客实时了解全线网列车运行情况，及时发现晚点列车。
- **Target Users**: 地铁运营监控人员、地铁调度中心、车站大屏展示

## Goals
- 实现1080×1920及以上高分辨率的大屏展示
- 在轨道线路图上实时显示运行中的地铁车辆
- 每分钟自动刷新列车位置和状态数据
- 鼠标悬浮显示列车详细信息（车次、运行状态、是否晚点）
- 通过颜色区分正常（绿色）和晚点（红色）列车

## Non-Goals (Out of Scope)
- 不实现地铁票务系统功能
- 不实现用户登录和权限管理
- 不实现历史数据查询和统计分析
- 不实现移动端响应式布局（专注大屏展示）
- 不实现列车控制和调度功能

## Background & Context
- 大屏数据可视化是城市交通监控的重要手段
- 香港地铁作为高密度城市轨道交通系统，需要高效的实时监控工具
- 采用Web技术栈实现，便于部署和维护

## Functional Requirements
- **FR-1**: 绘制香港地铁线路轨道图，包含主要线路和站点
- **FR-2**: 在对应股道上显示实时运行的地铁车辆图标
- **FR-3**: 每分钟自动刷新一次列车位置和状态数据
- **FR-4**: 鼠标滑动到列车图标上时，显示悬浮信息框
- **FR-5**: 悬浮信息框展示车次、运行状态、是否晚点等信息
- **FR-6**: 正常运行列车显示为绿色，晚点列车显示为红色
- **FR-7**: 支持1080×1920及以上分辨率显示

## Non-Functional Requirements
- **NFR-1**: 数据刷新时间误差不超过5秒
- **NFR-2**: 页面加载时间不超过3秒
- **NFR-3**: 支持至少50列列车同时渲染不卡顿
- **NFR-4**: 悬浮信息框响应时间不超过100ms
- **NFR-5**: 系统7×24小时稳定运行

## Constraints
- **Technical**: 使用前端Web技术栈（HTML/CSS/JavaScript），优先使用React + TypeScript
- **Business**: 大屏展示专用，固定分辨率布局
- **Dependencies**: 使用模拟数据，不依赖真实地铁API接口

## Assumptions
- 大屏设备支持现代浏览器（Chrome 90+）
- 网络连接稳定，保证数据刷新
- 列车数据格式符合预期结构

## Acceptance Criteria

### AC-1: 高分辨率大屏适配
- **Given**: 用户在1080×1920或更高分辨率显示器上打开系统
- **When**: 页面加载完成
- **Then**: 页面内容完整展示，无拉伸或变形，所有元素清晰可见
- **Verification**: `human-judgment`
- **Notes**: 在不同分辨率下测试显示效果

### AC-2: 地铁线路轨道图展示
- **Given**: 系统已启动
- **When**: 页面加载完成
- **Then**: 清晰显示香港地铁主要线路轨道和站点布局
- **Verification**: `human-judgment`

### AC-3: 列车在轨道上显示
- **Given**: 系统有列车运行数据
- **When**: 页面加载或数据刷新完成
- **Then**: 列车图标正确显示在对应轨道位置上
- **Verification**: `programmatic` + `human-judgment`

### AC-4: 数据每分钟自动刷新
- **Given**: 系统正常运行中
- **When**: 等待60秒
- **Then**: 列车位置和状态数据自动更新，用户可见刷新提示
- **Verification**: `programmatic`

### AC-5: 鼠标悬浮显示列车信息
- **Given**: 页面上有列车图标显示
- **When**: 用户将鼠标移动到列车图标上
- **Then**: 显示悬浮信息框，包含车次、运行状态、是否晚点
- **Verification**: `programmatic` + `human-judgment`

### AC-6: 列车颜色区分正常/晚点
- **Given**: 系统中有正常和晚点列车数据
- **When**: 列车图标渲染完成
- **Then**: 正常列车显示为绿色，晚点列车显示为红色
- **Verification**: `programmatic` + `human-judgment`

### AC-7: 信息展示准确性
- **Given**: 悬浮信息框已显示
- **When**: 查看信息内容
- **Then**: 车次、运行状态、晚点信息与数据一致
- **Verification**: `programmatic`
