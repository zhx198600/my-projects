# 后台订单管理系统 - Verification Checklist

## 基础功能验证
- [ ] 项目可正常启动（npm run dev 无报错）
- [ ] npm run build 无 TypeScript 编译错误
- [ ] 浏览器控制台无红色错误输出

## 认证系统验证
- [ ] 登录页面正确显示
- [ ] 输入 admin/admin123 可成功登录并跳转首页
- [ ] 输入错误密码显示错误提示
- [ ] 未登录访问 /orders 自动重定向到 /login
- [ ] 登录后刷新页面保持登录状态
- [ ] 点击退出登录清除状态并返回登录页

## 多语言切换验证
- [ ] 登录页右上角显示语言切换按钮
- [ ] 切换到英文后登录页面文本变为英文
- [ ] 登录后切换语言，整个管理后台文本同步切换
- [ ] 刷新页面后语言偏好保持不变

## 主题切换验证
- [ ] 登录页右上角显示主题切换按钮
- [ ] 切换到深色模式后页面配色正确（背景深色、文字浅色）
- [ ] 切换到浅色模式后页面配色正确（背景浅色、文字深色）
- [ ] 所有页面组件（表格、卡片、按钮）在两种主题下美观可读
- [ ] 刷新页面后主题偏好保持不变

## 系统布局验证
- [ ] 左侧侧边栏正确显示菜单（订单管理、物流管理、用户管理）
- [ ] 当前页面菜单高亮显示
- [ ] 顶部状态栏显示当前用户名称
- [ ] 点击菜单项正确跳转到对应页面
- [ ] 面包屑导航正确显示当前路径

## 订单管理验证
- [ ] 订单列表页面显示订单表格（至少 20 条数据）
- [ ] 表格列包含：订单号、客户名称、订单金额、订单状态、创建时间、操作
- [ ] 不同订单状态显示不同颜色标签
- [ ] 在搜索框输入订单号可过滤出对应订单
- [ ] 在搜索框输入客户名可过滤出对应订单
- [ ] 通过状态筛选下拉框可按状态过滤订单
- [ ] 点击"详情"按钮打开订单详情页面
- [ ] 订单详情页面显示完整订单信息
- [ ] 在详情页可修改订单状态
- [ ] 修改状态后返回列表，该订单状态已更新
- [ ] 列表支持分页功能

## 物流管理验证
- [ ] 物流列表页面显示物流表格
- [ ] 表格列包含：物流单号、关联订单号、当前状态、最后更新时间、操作
- [ ] 点击"查看"显示物流详情
- [ ] 关联订单号可点击跳转订单详情
- [ ] 支持按物流单号或订单号搜索

## 用户管理验证
- [ ] 用户列表页面显示系统用户表格
- [ ] 表格列包含：用户名、角色、状态、最后登录时间、操作
- [ ] Admin 角色与 User 角色有视觉区分
- [ ] 点击"禁用"按钮后用户状态变为禁用
- [ ] 点击"启用"按钮后用户状态变为启用
- [ ] 支持按用户名搜索

## 用户体验验证
- [ ] 操作成功后显示绿色成功提示
- [ ] 操作失败/出错时显示红色错误提示
- [ ] 页面加载时显示 Loading 状态
- [ ] 按钮点击期间进入加载状态，防止重复点击
- [ ] 空列表/无搜索结果时显示空状态提示
- [ ] 危险操作（如取消订单/禁用用户）前有确认弹窗

## 响应式与兼容性（桌面端）
- [ ] 窗口宽度 1280px+ 时布局正常
- [ ] 侧边栏在不同窗口宽度下显示正常（可折叠/展开）
- [ ] 表格在桌面分辨率下无水平滚动（或滚动条友好）
