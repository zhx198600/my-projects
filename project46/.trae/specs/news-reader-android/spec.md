# 新闻阅读安卓应用 - Product Requirement Document

## Overview
- **Summary**: 构建一款面向中文用户的安卓原生新闻阅读应用，提供新闻分类浏览、关键词订阅、夜间模式、收藏与历史记录、阅读时长统计、内容过滤与个性化推荐功能。
- **Purpose**: 为用户提供一个轻量、快速、可高度自定义的新闻阅读体验，帮助用户快速获取感兴趣的资讯，同时通过个性化推荐提升信息获取效率。
- **Target Users**: 普通手机用户、新闻资讯爱好者、有兴趣订阅特定关键词的人群。

## Goals
- 提供清晰的新闻分类浏览体验（如科技、财经、体育、娱乐、国际、社会等）。
- 支持关键词订阅，用户可订阅感兴趣词汇，相关新闻实时推送。
- 提供夜间模式与日间模式切换，保护长时间阅读的用户视力。
- 支持新闻收藏与阅读历史记录，便于用户回溯。
- 统计并展示用户阅读时长，提供每日/每周概览。
- 支持关键词与分类的内容过滤屏蔽，为用户提供可控的信息源。
- 基于用户阅读行为（点击、停留、收藏、订阅）提供个性化推荐。

## Non-Goals (Out of Scope)
- 不实现新闻内容的原创/编辑发布系统，仅展示第三方数据源。
- 不实现评论、社交互动或 UGC 功能。
- 不实现跨平台（iOS/网页）版本，本项目仅覆盖 Android。
- 不实现账户体系与云同步，数据仅在本地存储。
- 不实现后端服务与推送服务器，推送与推荐逻辑在本地完成（可替换为 Mock 数据源）。

## Background & Context
- 当前工作目录为空项目，需要从零搭建 Android 项目结构。
- 技术选型采用 Kotlin + Jetpack Compose 现代安卓 UI 框架，配合 MVVM 架构。
- 本地数据持久化使用 Room，网络层使用 Retrofit + OkHttp。
- 新闻数据源在开发阶段使用本地 Mock JSON，便于离线演示与测试。
- 个性化推荐采用基于关键词/分类的简单协同或加权打分策略，在本地离线计算。

## Functional Requirements
- **FR-1 新闻分类浏览**: 应用首页展示新闻分类 Tab，点击分类展示对应新闻列表，点击条目进入详情页。
- **FR-2 关键词订阅**: 用户可在订阅页面添加/删除关键词，订阅的关键词在推送中高亮或置顶相关新闻。
- **FR-3 夜间模式**: 设置页提供"日间/夜间/跟随系统"模式切换，切换后全应用主题立即生效。
- **FR-4 收藏**: 在新闻详情页或列表项长按可加入收藏，收藏列表可查看与移除。
- **FR-5 阅读历史**: 自动记录用户已阅读的新闻条目，提供历史列表与清空功能。
- **FR-6 阅读时长统计**: 统计用户在详情页的有效阅读时长，按日/周汇总并以柱状或列表展示。
- **FR-7 内容过滤**: 用户可屏蔽指定分类或关键词，被屏蔽内容不出现在首页与推荐流中。
- **FR-8 个性化推荐**: 首页顶部或独立 Tab 展示"为你推荐"列表，基于阅读、收藏、订阅行为加权计算。
- **FR-9 底部导航**: 提供"首页/推荐/订阅/我的"四个底部 Tab，Tab 间可自由切换。
- **FR-10 详情页**: 展示新闻标题、作者、发布时间、正文、图片，支持返回与收藏。

## Non-Functional Requirements
- **NFR-1 性能**: 冷启动 ≤ 2s；列表滚动在中低端设备（如 Android 9 以上、3GB RAM）保持 60fps。
- **NFR-2 可用性**: 关键流程（浏览→阅读→收藏）三步内可达；主要界面导航清晰一致。
- **NFR-3 兼容性**: 最低支持 API 24 (Android 7.0)，目标 API 34。
- **NFR-4 可维护性**: 采用 MVVM + Repository 分层，模块化目录结构，核心逻辑覆盖单元测试。
- **NFR-5 可访问性**: 夜间模式对比度 ≥ WCAG AA；主要控件支持 TalkBack。

## Constraints
- **Technical**: 语言 Kotlin；UI Jetpack Compose；架构 MVVM；本地数据库 Room；网络 Retrofit。
- **Business**: 无后端服务器，使用本地 Mock 数据源；不涉及隐私合规用户数据上传。
- **Dependencies**: Android Gradle Plugin、Compose BOM、Room、Retrofit、Coroutines、Navigation Compose、DataStore 等。

## Assumptions
- 用户设备至少 Android 7.0，具备网络访问能力（可离线查看已缓存新闻）。
- 新闻数据源在演示阶段使用本地 JSON 文件，不影响功能完整性。
- 推荐算法采用简单的基于关键词/分类的加权打分，暂不引入机器学习库。
- 夜间模式通过 Material3 动态主题实现。

## Acceptance Criteria

### AC-1: 新闻分类浏览
- **Given**: 用户已启动应用并位于首页
- **When**: 用户点击顶部任意新闻分类 Tab
- **Then**: 列表刷新显示该分类下的新闻条目，点击任一条目进入详情页
- **Verification**: `programmatic`
- **Notes**: 分类至少包含 6 个预置分类（科技/财经/体育/娱乐/国际/社会）

### AC-2: 关键词订阅
- **Given**: 用户位于"订阅"页面
- **When**: 用户在输入框输入关键词并点击添加
- **Then**: 关键词显示在订阅列表，首页出现包含该关键词的新闻高亮
- **Verification**: `programmatic`

### AC-3: 夜间模式切换
- **Given**: 用户位于"我的"页面
- **When**: 用户切换主题为夜间模式
- **Then**: 全应用界面立即切换为深色主题，设置持久化保存
- **Verification**: `human-judgment`
- **Notes**: 需在所有页面肉眼可见主题变化

### AC-4: 收藏功能
- **Given**: 用户在新闻详情页
- **When**: 用户点击收藏按钮
- **Then**: 按钮状态改变为已收藏，该新闻出现在"我的 > 收藏"列表中
- **Verification**: `programmatic`

### AC-5: 阅读历史
- **Given**: 用户阅读完一篇新闻后返回
- **When**: 用户进入"我的 > 历史"
- **Then**: 该新闻出现在历史列表，按时间倒序排列，可清空
- **Verification**: `programmatic`

### AC-6: 阅读时长统计
- **Given**: 用户在详情页阅读新闻
- **When**: 停留超过 3 秒且未锁屏，阅读时长被累计
- **Then**: "我的 > 阅读统计"展示当天/当周累计时长
- **Verification**: `programmatic`

### AC-7: 内容过滤
- **Given**: 用户在"我的 > 内容过滤"添加屏蔽关键词
- **When**: 返回首页或推荐页
- **Then**: 包含该关键词的新闻不再显示
- **Verification**: `programmatic`

### AC-8: 个性化推荐
- **Given**: 用户有阅读、收藏、订阅行为
- **When**: 用户进入"推荐" Tab
- **Then**: 展示基于用户行为加权排序的新闻列表
- **Verification**: `programmatic`

### AC-9: 底部导航
- **Given**: 用户在任意一级页面
- **When**: 点击底部导航图标
- **Then**: 平滑切换到对应 Tab 页面，保持当前页面状态
- **Verification**: `human-judgment`

### AC-10: 详情页展示
- **Given**: 用户在任意列表点击新闻
- **When**: 进入详情页
- **Then**: 展示标题、作者、时间、正文与图片，并可返回上一页
- **Verification**: `human-judgment`
