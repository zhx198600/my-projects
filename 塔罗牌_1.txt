## 数据结构说明

### 1. tarotCards.js（22张大阿卡纳牌）

每张牌包含以下字段：
- `id`: 编号 (0-21)
- `name`: 中文名称
- `nameEn`: 英文名称
- `element`: 元素（火、水、风、土）
- `zodiac`: 关联星座/行星
- `meaningUp`: 正位含义（约70-80字）
- `meaningDown`: 逆位含义（约70-80字）
- `keywords`: 关键词数组（5个）

**22张牌完整列表：**
0.愚者、1.魔术师、2.女祭司、3.皇后、4.皇帝、5.教皇、6.恋人、7.战车、8.力量、9.隐士、10.命运之轮、11.正义、12.倒吊人、13.死神、14.节制、15.恶魔、16.塔、17.星星、18.月亮、19.太阳、20.审判、21.世界

### 2. personalityData.js（性格分析数据）

每条数据包含以下字段：
- `cardId`: 对应牌的id（0-21）
- `keywords`: 性格关键词数组（5个）
- `strengths`: 优点描述（约120-140字）
- `weaknesses`: 缺点描述（约120-140字）
- `careers`: 适合职业数组（7个）
- `relationships`: 人际关系建议（约120-140字）

### 3. fortuneTemplates.js（运势模板数据）

包含5个维度的运势模板：
- `overall`: 整体运势
- `love`: 爱情运势
- `career`: 事业运势
- `wealth`: 财运运势
- `health`: 健康运势

每个维度包含：
- `positive`: 正位模板数组（3个）
- `negative`: 逆位模板数组（3个）

使用 `{变量名}` 格式的占位符，可在使用时动态替换为具体卡牌信息。

### 4. index.js（统一导出）

- 支持命名导出：`import { tarotCards, personalityData, fortuneTemplates } from './data'`
- 支持默认导出：`import data from './data'`

## ✨ 动画实现方式

### CSS 3D 翻牌动画

```scss
// 核心 CSS 结构
.card-container {
  perspective: 1000px;          // 3D 透视视角
}

.card-inner {
  transition: transform 0.8s;    // 翻牌动画时长
  transform-style: preserve-3d;  // 保持 3D 空间
}

// 正位翻牌
.card-inner.flipped {
  transform: rotateY(180deg);    // 沿 Y 轴翻转 180°
}

// 逆位翻牌（额外旋转 180°）
.card-inner.reversed {
  transform: rotateY(180deg) rotate(180deg);
}

.card-front, .card-back {
  backface-visibility: hidden;   // 背面不可见
}

.card-front {
  transform: rotateY(180deg);    // 正面默认朝后
}
```
